# Where this folder comes from

This is a **verbatim copy** of `figma-desktop-bridge/` from
https://github.com/southleft/figma-console-mcp — the "Figma Desktop Bridge" plugin by
[Southleft](https://southleft.com), MIT licensed. Copyright (c) 2025 Figma Console MCP
Contributors. Its license is in `LICENSE` and its own documentation in `README.md`, both
kept exactly as published.

Nothing here was written or modified by figbridge. It is bundled only so that installing
figbridge is a double-click instead of a git clone. **Do not patch these files** — if
something needs fixing on the plugin side, it belongs upstream.

Upstream does more than figbridge uses: a cloud relay for web-based AI clients, browser
console tooling, and its own MCP server. If any of that sounds useful, go there.
